# ESP32 Web Dashboard

Project ini bertujuan untuk menerima dan menampilkan data dari perangkat ESP32 ke dalam sebuah interface web yang mudah diakses oleh pengguna.

## Alur Sistem

1. **ESP32**: Membaca sensor dan mengirimkan data secara berkala.
2. **Backend / Cloud**: Menerima data dari ESP32 (bisa menggunakan MQTT, HTTP API, atau layanan cloud seperti Firebase).
3. **Frontend Web**: Menampilkan data secara real-time dengan UI yang modern dan menarik.
